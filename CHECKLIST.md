# Pre-submission checklist

## Before you build
- [ ] Decide the final application ID — it is permanent once published
- [ ] Create the upload keystore and back it up somewhere you will not lose it
- [ ] Enrol in Play App Signing on first upload
- [ ] `versionCode 1`, `versionName "1.0.0"`

## Test on a real device
- [ ] Launch screen flows into the in-app flag animation without a flash of white
- [ ] Aeroplane mode: every screen works, including fonts and text-to-speech
- [ ] Rotate to landscape — layout stays centred and readable
- [ ] Gesture navigation: nothing sits under the status bar or home indicator
- [ ] Dark mode and light mode both correct; system auto-switch works
- [ ] Largest text size setting does not clip any button
- [ ] Complete a full 24-question mock test and check the timer expires correctly
- [ ] Kill and reopen the app — progress, streak and test history survive
- [ ] Back button from a chapter returns to the list, and from home exits
- [ ] Text-to-speech works, and degrades gracefully on a device with no voice

## Play Console
- [ ] Price set before first production release
- [ ] Privacy policy hosted at a public URL and entered
- [ ] 2–8 phone screenshots uploaded
- [ ] Feature graphic and 512px icon uploaded
- [ ] Data safety form completed as "no data collected"
- [ ] Content rating questionnaire completed
- [ ] Target audience set to 18+
- [ ] Contact email set
- [ ] Internal testing track first — install from Play, not just from Studio

## Legal
- [ ] Disclaimer of Home Office affiliation present in the listing AND in the app
- [ ] No official crest, crown or coat of arms anywhere in the listing
